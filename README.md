# Akshay Kumar Bishnoi — Research Portfolio

An accessible, responsive static research portfolio with an animated road, scroll-driven journey, project evidence, research direction, CV and research-statement request links. Content is grounded in the supplied CV and application documents dated October 2026.

Open index.html or serve this folder with any static web server. No build step, API keys, backend, or paid dependencies are required. Fonts use Google Fonts with system fallbacks. Research demos are external Streamlit apps and may take time to wake up.

Publish the folder to GitHub Pages or Netlify. For GitHub Pages, choose the main branch and root folder in repository Settings → Pages.

Edit index.html for content, style.css for appearance, and script.js for animation. Original PDFs are retained locally and are not published. Phone number and university-specific application letter are not part of the public portfolio.
