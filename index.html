2026–PRESENT · COLLABORATIVE WORK IN PROGRESS

MACE-X²

Multi-Witness Medical Image Anomaly Detection

Normal-only chest X-ray anomaly detection on NIH ChestX-ray14, using frozen ResNet18 global embeddings and position-aware 7×7 local evidence.

0.6624Global baseline AUROC
0.8107Witness Pearson correlation
The result that shaped the next question

The validation-locked 0.75/0.25 global–local combination showed no clear AUROC gain: Δ −0.0018, patient-cluster bootstrap 95% CI [−0.0043, +0.0007]. More signals did not establish more independent evidence.

Experimental context & limitations

Patient-disjoint PA-view cohorts: 13,870 train / 16,794 validation / 17,119 test. Global cosine 3-NN, PCA reconstruction, and spatial evidence were investigated. Global baseline AUPRC: 0.8943; precision–recall performance depends on cohort prevalence. Ranking stability was audited under ±10% brightness changes. Manuscript in preparation; these findings are not a claim of clinical validation.

2023–2025 · M.SC. THESIS SUBMITTED 2025

Learning to see pneumonia.

Deep learning for chest X-ray classification

I compared three model families, developed five experimental notebook versions, and examined model behaviour with class-specific Grad-CAM and statistical comparisons.

293Independent hospital radiographs
82.25%Hospital accuracy · ResNet50V2 V2
Internal performance is only part of the story

ResNet50V2 V5 recorded approximately 95.31% best-validation accuracy; V2 reached 82.25% accuracy on the independent hospital cohort. These refer to different model versions and evaluation settings.

Experimental context & limitations

Public dataset: 5,856 images (original split: 5,216 train / 16 validation / 624 test). Later versions used a 10% validation split, controlled seeds, early stopping, and validation-based checkpoints. Hospital ResNet50V2 V2: sensitivity 88.33%, specificity 78.04%, F1 80.30%. V5 had the highest reported hospital AUC, 0.876. Analyses included Cohen’s κ, McNemar, and DeLong tests. The demo is for research exploration.

03 / THE QUESTION AHEAD

Learning relevant
normality.

My proposed doctoral direction: reliability-aware representation learning for unsupervised medical image anomaly detection.

THE CENTRAL QUESTION

Which features make an image anomalous—and are those features anatomically relevant and reliable?

01 / SENSITIVITY

Respond to
structure.

Use plausible synthetic anomalies to encourage sensitivity to anatomical deviations, beyond intensity differences.

02 / INVARIANCE

Resist the
nuisance.

Evaluate stability under controlled contrast, intensity, and acquisition-like perturbations that preserve anatomy.

03 / COMPLEMENTARITY

Count independent
evidence.

Measure redundancy across global and spatial representations; investigate uncertainty and abstention.

Proposed evaluation: patient-disjoint cohorts, AUROC/AUPRC, localisation where available, patient-level bootstrap uncertainty, robustness, and selective-risk analysis.
